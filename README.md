# BOLID Alarm Pro — реалистичный стенд ОПС для Minecraft 1.7.10 Forge

Это исходники мода, в котором приборы ИСО «Орион» / BOLID ставятся на стенд,
соединяются настоящими (в рамках симуляции) линиями и ведут себя как система
пожарной сигнализации и автоматического порошкового пожаротушения: питание,
адреса, опрос, обрывы, КЗ, оконечные резисторы, терминаторы RS-485, задержки
пуска, табло, пиропатрон, журнал событий.

> **Статус:** в репозитории готовая кодовая база, текстуры, lang-файлы,
> `build.gradle`, документация и самопроверки. Готовый `.jar` не лежит в репозитории:
> в песочнице недоступны Maven-хосты Forge/Mojang, поэтому финальная сборка
> делается у вас командой `gradle build`. Все 40 основных исходников проверены
> полной компиляцией ECJ против точной библиотеки `forgeSrc` Forge 10.13.4.1614
> (минимальные compile-time заглушки только для LWJGL и Netty); все 41 Java-файл
> проходят синтаксическую проверку, а чистое ядро — 39 автономных проверок.

## «Максимально реалистично» — что именно реализовано

* **Электротехника:** падение напряжения от тока и длины кабеля, бюджет 2 А / 3 А,
  АКБ с интеграцией заряда/разряда, короткое замыкание, обрыв, обратная полярность,
  повреждение 12-вольтового табло при подаче 24 В.
* **RS-485:** уникальные адреса 1…127, дубли, два терминатора 120 Ом, перепутанные A/B,
  качество линии и детерминированные потери пакетов.
* **ДПЛС:** два выхода КДЛ, кольцевая топология, обрыв с опросом с двух сторон,
  КЗ и локализация встроенным БРИЗ у УДП, 15 с техготовности, 300 мс доставки события,
  напряжение в точке подключения.
* **АСПТ:** три контролируемых ШС с EOL, датчик двери, логика «два извещателя»,
  раздельные задержки 30/15 с, мигание световых оповещателей, 15-секундный пусковой
  импульс, режим «Тушение» и ожидание сброса, контроль цепей запуска на обрыв/КЗ.
* **События:** ИПР и УДП → КДЛ → RS-485 → С2000М; на 5.02 команда уходит на АСПТ
  с настраиваемым сетевым адресом. Журнал пульта и глобальный журнал симуляции.
* **Визуал:** отдельные рисованные 256×256 передние панели под каждый прибор,
  тонкие 3D-корпуса с поворотом по стороне света, живые LED-индикаторы, зелёный ЖКИ
  2×16 прямо на блоке, двусторонние табло с яркой/тёмной текстурой, цветные кабели.
* **GUI:** PProg/UProg-подобный экран состояния, конфигурации и журнала; адреса,
  каналы портов, включение выходов, автоматика, дверь, извещатели, АКБ, тест 24 В,
  замена пиропатрона, сброс повреждения.
* **Мир:** сработавший пиропатрон тушит `Blocks.fire` в радиусе и рассылает клиентам
  пакет с частицами порошка; сетевой ввод можно отключать, кабели можно рвать и закорачивать.

Подробная таблица соответствий и упрощений — в [docs/REALISM.md](docs/REALISM.md),
пошаговый стенд и эксперименты — в [docs/STAND.md](docs/STAND.md),
полный список источников — в [docs/SOURCES.md](docs/SOURCES.md).

## Сборка

Нужны **JDK 8**, **Gradle 2.3** и доступ к репозиториям Forge/Mojang.

```bash
gradle setupDecompWorkspace   # один раз, для IDE
gradle build                  # -> build/libs/BolidAlarmPro-1.7.10-0.1.0.jar
gradle simTest                # чистый self-test без запуска Minecraft
```

`mcmod.info`, `ru_RU.lang`, `en_US.lang` и все PNG уже сгенерированы.
Если хотите перегенерировать ассеты:

```bash
python3 -m pip install Pillow javalang
python3 tools/generate_textures.py
python3 tools/generate_lang.py
python3 tools/validate_sources.py
sh tools/run_sim_test.sh       # если установлен javac
```

## Управление одной фразой

* ПКМ по прибору пустой рукой — открыть GUI (у ИПР/УДП — нажать кнопку;
  с `Shift` — всё равно открыть GUI).
* ПКМ с **программатором** — GUI прибора / смена канала кабеля.
* ПКМ с **мультиметром** — диагностика кабельной сети.
* ПКМ с **ключом** — сброс ИПР/УДП; с **АКБ** — установка в РИП-12/АСПТ.
* ПКМ с **EOL**, **терминатором**, **КЗ-перемычкой** — внести/снять неисправность или оконечный элемент.
* В GUI: вкладки «Состояние / Конфигурация / Журнал», кнопки пуска, отмены, сброса,
  автоматики, двери, извещателей, выходов и адресов.

Кабели одного типа и канала объединяются в сеть; разные каналы — независимые линии.
Клемма прибора подхватывает кабель в радиусе до 3 блоков, чтобы у АСПТ хватило
места на все ШС и выходы.

## Проверено

* `javalang`: 41 Java-файл, 0 синтаксических ошибок.
* Пакет `sim` не импортирует `net.minecraft`, `cpw.mods.fml`, `net.minecraftforge`, `org.lwjgl`.
* Полная компиляция 40 основных исходников через ECJ 3.41 против `forgeSrc`
  для `1.7.10-10.13.4.1614-1.7.10`: 49 классов, 0 ошибок. Для отсутствующих в
  песочнице LWJGL/Netty использованы только минимальные заглушки сигнатур.
* `SimSelfTest`: 6 групп / 39 проверок — питание, АКБ, КЗ, 24 В, RS-485, ДПЛС,
  EOL, ИПР, УДП, дистанционный пуск, табло, пиропатрон, автопуск и дверь.

## Дисклеймер

Неофициальный фанатский мод. Товарные знаки BOLID, Orion, С2000, РИП, ИПР, УДП,
VISTL и Молния принадлежат правообладателям. Модели и прошивки не являются
побайтовой копией реальных устройств; это обучающая симуляция, а не руководство
по монтажу реальных систем пожарной безопасности.
